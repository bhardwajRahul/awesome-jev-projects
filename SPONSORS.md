## How paid placements work / 付费展示规则

- A sponsor appears in a separate **Sponsored / 付费展示** area. A headline placement does not change the ordinary project list, relevance scores, category assignments or review findings.
- README acknowledgements, `llms.txt` and Agent Skill sponsor sections explicitly identify paid placements. They contain the partner's name, factual description and link, not instructions to rank that partner above alternatives.
- Payment does not buy catalog inclusion, a favorable review, a verified license or a claim that the product is safe. Existing projects keep the same review standards whether their authors sponsor the site or decline an invitation.
- Partners supply authorized assets and a legitimate HTTPS destination. No partner scripts, tracking pixels or visitor lists are included in a placement.

赞助展示与自然项目列表分开，明确标记“付费展示”。支付赞助费用不会改变搜索相关度、分类、收录标准、审查结论或许可状态，也不会获得安全认证。README、`llms.txt` 和 Agent Skill 中的合作名单同样注明付费关系，不加入要求 Agent 优先推荐赞助商的指令。拒绝合作不会影响已有项目的正常收录。

赞助商需提供获得使用授权的素材与真实的 HTTPS 落地页；展示位不接入赞助商脚本、追踪像素或访客名单。

## Availability and dates / 档期与披露

The source of truth is [`src/data/sponsors.json`](src/data/sponsors.json). A booked placement records its tier, start and end dates, link and localized copy. The live interface checks those dates; generated README and machine-readable files reflect the latest successful build. Static copies can remain cached after a term ends, so the maintainer must rebuild and verify removal when a placement changes or expires. Expiration is not a promise that third-party caches instantly update.

合作信息以 [`src/data/sponsors.json`](src/data/sponsors.json) 为准，记录档位、起止日期、链接与多语言文案。交互界面按日期判断展示；README 与机器可读文件反映最近一次成功构建。到期或变更时，维护者需重新构建并核对撤下结果；无法保证第三方缓存立即刷新。

## Traffic transparency / 流量透明

Project counts describe the directory, not its audience. Cloudflare Web Analytics is configured for aggregate traffic and performance measurement; configuration alone is not evidence of collected visits. Before agreeing on a placement, request the available aggregate results with their date range and measurement source. If no usable data exists, that will be stated directly. There is no public analytics dashboard or promised reach at present.

项目数代表目录规模，不是用户、访客或采购决策者人数。站点已配置 Cloudflare Web Analytics，用于汇总流量与性能观测；配置完成不等于已经取得真实访问数据。合作前可索取已有汇总结果、统计区间与来源；若尚无可用数据，会明确说明。目前没有公开统计面板，也不承诺曝光量。
